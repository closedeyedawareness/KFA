# Keys From Above

Official website for Adelmar van Dijk / Keys From Above — pianist, composer, producer.

Static site, hosted on GitHub Pages with a custom domain (www.keysfromabove.com).

## Structure
- `index.html` — single-page site with anchor-linked sections (Home, About, My Music, Mediakit, Piano Samples, Meditations, Contact)
- `styles.css` — styling
- `assets/` — background imagery and logo, exported from the original Canva design
- `CNAME` — custom domain config for GitHub Pages

## Local preview
Just open `index.html` in a browser, or serve the folder with any static file server.
